# :chart_with_upwards_trend: Magnitude detector

A Streamlit dashboard that measures move magnitude from options data:

- **Implied move** — the move the market is pricing in per expiry, from ATM
  straddle prices (85% rule) and from ATM IV (`S × σ × √(DTE/365)`).
- **Unusual activity** — contracts with outsized volume vs open interest and
  meaningful traded premium, ranked by a composite percentile score.
- **Price moves** — days where the underlying's return exceeds a z-score
  threshold vs its trailing volatility, plus volatility bursts.
- **IV spikes** — chain-snapshot IV outliers (robust z vs the expiry median)
  and one-day IV jumps over time.

The app ships with a synthetic sample chain and price history, so it works
out of the box — upload your own CSVs in the sidebar to analyze real data.

### How to run it on your own machine

1. Install the requirements

   ```
   $ pip install -r requirements.txt
   ```

2. Run the app

   ```
   $ streamlit run streamlit_app.py
   ```

### CSV format

Column names are matched flexibly (case, spacing and punctuation ignored).
Canonical columns and accepted aliases for the options-chain CSV:

| Column | Accepted names (examples) |
|---|---|
| type | type, cp_flag, call/put, option_type, right, side |
| strike | strike, strike_price, k |
| expiration | expiration, exp date, expiry, maturity |
| bid / ask / last | bid, ask, offer, last, price, mark, mid |
| volume | volume, vol, total_volume |
| open_interest | open_interest, oi, open_int |
| implied_volatility | implied_volatility, iv, imp_vol, sigma |
| underlying_price (optional) | underlying_price, spot, stock_price |
| timestamp (optional) | timestamp, date, quote_date, as_of_date |

IV given in percent (e.g. `32.5`) is detected and rescaled to decimals.
If the spot price is missing, it is inferred from put–call parity. Columns
that can't be auto-matched can be assigned manually in the sidebar, and each
detector explains what it needs if something is missing.

The optional price-history CSV needs `date` and `close`, plus an optional
`iv` column to enable IV-spike detection over time.

Sample data is generated by `scripts/generate_sample_data.py` (deterministic,
seeded) with planted anomalies so every detector has something to find.
